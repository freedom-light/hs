# PXT鸿蒙信号

只读的安卓小工具：打开后一屏列出设备的 Build 字段、几项系统属性，以及所有名字或值里带 `anco` 的系统属性，用来判断当前是否运行在鸿蒙的安卓兼容环境里。

- 不申请任何权限，不联网，不写任何文件。
- 安装包：[`s.apk`](s.apk)（debug 签名）。
- 源码：[`src/`](src)，用 `build.sh` 直接以 aapt2 / javac / d8 打包，不依赖 Gradle。

## p.apk：实况分享实验包

[`p.apk`](p.apk) 用来验证「通过系统分享保存实况图」在不同系统上的表现。内置一张合成的实况样图（画面是「H40」字样），按钮「R 页内横幅 + 分享」会把它交给系统分享面板。不联网。
